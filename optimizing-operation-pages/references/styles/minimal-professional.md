# 风格包：minimal-professional（极简专业）

**适用**：专业工具、内部平台、配置中心——使用者是熟练用户，内容与层级优先，装饰归零。
**不适用**：需要品牌感/亲和力的对外页面、依赖色彩引导的新手流程。

## Design Token

| 维度 | 取值 |
|---|---|
| 信息密度 | 中等偏紧：表格行高 40px，组件默认 size |
| 字号 | 正文 13-14px，辅助 12px，页面标题 16-18px（semibold，不放大太多） |
| 间距 | 基准 8px，区块间 16px，靠留白而非线框分组 |
| 圆角 | 6px，全局统一一个值 |
| 边框 | 细 1px 低对比边框（#E4E4E7 级）是唯一分区手段，无阴影无底色块 |
| 色彩 | 纯白或近白底 + 近黑文字层级（#18181B / #52525B / #A1A1AA 三级）；彩色只出现在状态与链接 |
| 动效 | 极克制：仅 hover 背景变化与焦点环，≤120ms，无位移动画 |

## 主题色候选（3 选 1，默认第一个）

| id | 名称 | primary | hover | active | soft |
|---|---|---|---|---|---|
| `near-black` | 中性近黑（默认） | #18181B | #27272A | #09090B | #F4F4F5 |
| `graphite-blue` | 石墨蓝 | #334155 | #475569 | #1E293B | #F1F5F9 |
| `muted-indigo` | 低饱和靛 | #4F46E5 | #6366F1 | #4338CA | #EEF2FF |

near-black 主题下链接与焦点色用 #2563EB，避免链接与正文无法区分。

## 字体候选（3 选 1，默认第一个；全部系统自带字体，零加载，中文差异肉眼可见）

| id | 名称 | font-family |
|---|---|---|
| `yahei` | 雅黑（默认） | -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif |
| `dengxian` | 等线（更轻瘦） | "DengXian", "等线", "PingFang SC", "Microsoft YaHei", sans-serif |
| `songti` | 宋体（文档风） | "SimSun", "宋体", "Songti SC", "Microsoft YaHei", serif |

数字列建议统一 `font-variant-numeric: tabular-nums`。宋体候选适合审阅/文档型页面，小字号下屏显锐利，慎用于高密度表格。macOS 无雅黑/等线时回退苹方，不算缺陷。

## 布局骨架

单平面极简布局：页头（小标题 + 右侧主操作）→ 内联筛选行（无底色，控件裸放）→ 细边框表格 → 极简分页（仅上一页/下一页 + 页码输入）。整页只有一层背景色，区块靠间距与 1px 分隔线区分。

## 组件规则

- **表格**：仅横向分隔线；表头小字号大写或加粗灰字；状态用小圆点 + 文字（不用彩底标签）；hover 行浅灰背景；行内操作默认隐藏、hover 浮现。
- **筛选**：裸控件内联排列；已选条件直接改写控件显示值而非另加标签行；支持键盘快捷键（/ 聚焦搜索）。
- **表单/弹窗**：居中小模态或右侧窄抽屉；单列、label 上置小灰字；校验信息就近红色小字。
- **操作层级**：主操作近黑实心；次操作细边框白底；危险操作红字文字按钮 + 确认；图标按钮必须带 tooltip。
- **状态**：加载用顶部细进度条 + 局部骨架；空状态一句话 + 一个动作，无插画；错误内联红字条。

## 实现映射

Headless（Radix/Headless UI）+ Tailwind zinc 色阶是天然实现。AntD：`borderRadius: 6` + 线性化主题 token（去阴影、灰阶色板）。Element Plus：中性色变量覆盖。无组件库：zinc/gray 色阶 CSS 变量 + 1px 边框体系。
