# 风格包：cloudflare-console（云控制台）

**适用**：资源多、模块多的平台型后台（云服务、开发者平台、多产品线管理台）——用户靠搜索和"最近访问"跳转，在列表、详情、设置之间高频切换。
**不适用**：单一业务、只看一张表的审核/订单页（资源级导航显得多余）；大屏监控；需要强品牌营销感的对外页面。

> 数据来源：2026-10-28 在 Edge 中实测 dash.cloudflare.com（Kumo 设计系统，Tailwind v4 + Base UI），读取计算样式、CSS 变量与埋点计时。标"推导"的值为非实测补全。控制台中仍有旧版页面（5px 圆角、#B6B6B6 实线边框、#D9D9D9 表头），本风格包只取新版 Kumo 的 token，旧版仅借鉴"设置卡"结构。

## Design Token

| 维度 | 取值 |
|---|---|
| 信息密度 | 中等：按钮/输入框高 36px，表格行高 40px，侧边栏项高 34px；内容区居中、有最大宽度 |
| 字号 | 页面标题 30px/600；弹窗标题 24px/600；KPI 数字 24px/600；正文与按钮 14px；导航、表单 label 13px/500；角标、KPI 标签 12px/500。不用 700 粗体；不改字距（不用 tracking）；行内等宽字（哈希、命令）缩到 0.9em；英文标题用句首大写（Recent requests） |
| 间距 | 基准 8px；工具栏按钮间距 8px；区块间 32-48px。标题与说明的间距小于它们与下方内容的间距（如 6px 对 24px）；容器内边距竖向略小于横向（如 16px 20px）；嵌套圆角同心（外圆角 = 内圆角 + 内边距） |
| 圆角 | 按钮、输入框、卡片、导航项 8px；弹窗和大搜索框 12px；下拉选项 4px；提示气泡 6px；角标胶囊（完全圆角） |
| 边框 | 不用 border：卡片、输入框、按钮统一用 `box-shadow: 0 0 0 1px rgb(10 10 10 / .1)` 描边；表格行分隔线 1px #E5E5E5 |
| 阴影 | 按钮 `0 1px 2px rgb(0 0 0 / .05)`；下拉框 `0 10px 15px -3px rgb(0 0 0 / .1)`；弹窗两层 3% 大范围柔和阴影 |
| 背景 | 页面 #FBFBFB；卡片、控件 #FFFFFF；凹陷区和悬停 #F3F3F3；图表外框 #F8F8F8 |
| 文字 | 主文字 #171717，最深一档 #0A0A0A，次要 #737373，占位符 #A1A1A1，禁用 #D4D4D4，链接 #0051C3 |
| 语义色 | 成功 #009966，警告 #FA8900，危险 #FB2C36（文字用 #C10007），信息 #2B7FFF；每种配一个浅色底（如成功 #DCFBE6、危险 #FFE2E2） |
| 图表色 | 系列依次为 #4290F0、#F5B647、#E8649D、#8D58EE |
| 品牌橙 | #F6821F：只出现在 Logo、"已代理"云图标、CLI 命令文字、推广按钮，不用于主操作 |
| 动效 | 见下文「交互与响应」：浮层 150ms 缩放淡入，嵌在页面里的变化（展开、勾选）瞬间完成 |

暗色模式（只读取了 token，没有实际切换看过）：页面 #030303，卡片 #0F0F0F，描边 #333333，主色 #005AEB，主文字 #F5F5F5，次要文字 #A1A1A1，链接 #50A2FF，成功色 #00D492。

## 主题色候选（3 选 1，默认第一个）

| id | 名称 | primary | hover | active | soft |
|---|---|---|---|---|---|
| `cf-blue` | 控制台蓝（默认） | #056DFF | #1447E6 | #045EDE | #DCEBFF |
| `cf-orange` | 品牌橙 | #F6821F | #FF9B62 | #E25A00 | #FFF4EC（推导） |
| `neutral-ink` | 中性墨 | #171717 | #262626（推导） | #0A0A0A | #F3F3F3 |

- **主按钮**不是纯色，而是从上到下的渐变：`linear-gradient(#3C86FF, var(--op-primary))`，外加 1px 描边（`var(--op-primary-active)`）和 `0 1px 2px rgb(0 0 0 / .05)` 投影。悬停时只把渐变顶部提亮到 #619EFF，底部不变。cf-orange 主题照此处理，渐变顶部用 hover 色。
- **cf-blue 取值来源**：hover 是 Kumo 的 brand-hover token，active 取自主按钮描边色，soft 取自 info-tint 底色。cf-orange 的 hover 和 active 取自首页推广按钮的底色和描边。

## 字体候选（2 选 1，默认第一个；零加载）

| id | 名称 | font-family |
|---|---|---|
| `inter-yahei` | Inter + 雅黑（默认） | "Inter", -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif |
| `dengxian` | 等线（更轻瘦） | "DengXian", "等线", "PingFang SC", "Microsoft YaHei", sans-serif |

原站使用 Inter Variable（自带）+ Paper Mono（等宽）。按预览契约不加载外部字体：本机装了 Inter 才会生效，否则回退到系统西文字体。哈希、ID、CLI 命令统一用等宽字体栈 `ui-monospace, "Cascadia Mono", Consolas, monospace`，KPI 数字用 `tabular-nums`。

## 布局骨架

左侧固定侧边栏（260px，可收起到 57px 图标栏）+ 很轻的顶栏 + 居中、有最大宽度的内容区，列表页可再加一列右侧信息栏。

- **侧边栏**：顶部是账户切换（Logo + 当前账户 + ⇅）和快速搜索框（带 `Ctrl K` 提示），往下是带灰色小标题的分组导航。进入某个资源后，侧边栏整体换成这个资源的菜单，顶部出现「Back to …」，子菜单左侧有一条竖线。侧栏顶部账户区与顶栏同高 58px、底边各 1px，与侧栏右边框交成"十字线"（吸顶的顶栏一律用 1px border 与滚动内容隔开）；侧栏底部 48px 底栏（顶边 1px）只放收起按钮。搜索框 32px 高、白底、ring 描边 + 极浅阴影；Ctrl K 提示不加键帽框，12px 灰字，"Ctrl" 再降到 50% 透明度。
- **顶栏**：左侧是面包屑加资源/环境切换（如 `myrr-test.top · free ⇅`、`生产 ⇅`），右侧只有「询问 AI」「支持」和头像。
- **列表页**：页头（标题 + 文档角标 + 一句说明，右上主操作）→ 工具栏（搜索框和按钮在同一行）→ 表格或卡片列表 → 分页；右侧可选一列固定信息栏（配额进度条、计费环形图、2×2 小 KPI）。
- **详情页**：顶部是一排分段标签（浅灰轨道里，当前项白底加描边），右侧是操作按钮；下面是若干面板卡（灰底小标题 + 胶囊标签 + 右侧 →），内容区按列放 KPI。
- **首页**：先是居中大标题（随机问候语）和大搜索框，然后是三列快捷入口（资源 / 资源 / 最近访问），最后是 Analytics。
- **设置页**：用"设置卡"——左侧约 2/3 放标题和说明，右侧约 1/3 是灰底控件区，底部一条页脚放「API ▸」链接。

## 组件规则

- **表格**：用 div + role 实现；只有横向分隔线，表头 14px/500，可带 ⓘ 说明和排序箭头；行悬停变浅灰；行尾是文字按钮「编辑」；表格上方一行写配额，如「已使用 13 / 200」。不能编辑的行用锁图标，按钮显示「查看」，也不能勾选。
- **工具栏**：搜索框和带图标的次按钮放在一行，主操作放在最右；搜索、筛选、排序、刷新也可以拼成一个整体的分段控件。
- **筛选**：一个构建器，每条条件由「字段 / 运算符 / 值」三个控件加删除图标组成，下方有「+ 添加筛选器」，右下是「取消 / 应用」；条件没填完时「应用」禁用。
- **按钮层级**：
  - 主操作：渐变实心。
  - 次操作：白底加 1px 描边。
  - 工具操作：无边框图标按钮（`+`、刷新、`···`）。
  - 危险操作分两级：行内用描边样式的红字加垃圾桶图标，确认框里用红色实心按钮，按钮文案带数量（如「删除 1 个记录」）。
- **表单**：label 放在输入框上方（13px/500），几个字段可以排在同一行；弹窗顶部放一句随输入实时更新的大白话，说明这条配置的含义；「保存」在左、「取消」在右。
- **复选框**：选中后是近黑色实心，表头复选框支持半选状态，选中的行变浅灰底。
- **KPI 卡**：12px 灰色标签 → 24px 数字 → 绿色或红色趋势百分比 → 贴着卡片底边的迷你折线图；没有数据时显示灰色胶囊「无数据」，背后是一条淡灰波浪线。
- **图表卡**：两层框——外层浅灰，放标题和「分组方式」下拉；内层白卡片，放图例和图表。Top-N 排行用 6px 高的胶囊进度条（灰色轨道 #E5E5E5，主色填充）。两层框本身就是一个组件（Kumo 的 LayerCard），不能再嵌套一层两层框。
- **状态显示**：小圆点或竖条加文字（如「就绪」）；来源用白底胶囊角标；说明性文字用斜体灰字。
- **空状态**：线性图标 + 标题 + 一句说明 + 一段可复制的 CLI 命令（品牌橙等宽字，浅灰底，8px 圆角）。不用插画。
- **下拉框**：白底，8px 圆角，描边加较大投影；选项高 33px，内边距 6px 8px，悬停浅灰底，选中项右侧打勾。
- **提示气泡**：白底、带小箭头、6px 圆角、14px 深色字、内边距 6px 10px、中等投影。不是黑底气泡。
- **抽屉**：右侧 450px 宽，左侧一条描边，**把主内容往左推**，不盖在内容上；窗口窄于 880px 时全屏。

## 交互与响应

核心原则：**先给反馈，再等数据**。点击后几十毫秒内界面一定有变化，数据分阶段补上，已经显示的内容尽量不清空。

### 跳转与加载时序（实测）

| 阶段 | 时间 | 表现 |
|---|---|---|
| 点击后 | 约 5ms | URL 改变（单页应用内跳转，不刷新整页） |
| | 约 10ms | 侧边栏目标项高亮，不等数据 |
| | 约 40ms | 侧边栏和顶栏切换到新的上下文 |
| 首次进入 | 1-2s | 内容区居中转圈加「正在加载…」 |
| | 随后 | 页面标题和外框先出现 → 表格按真实列宽显示骨架行（闪光动画）→ 数据填入 |
| 再次进入（已缓存） | 170-250ms | 标题出现；内容 220-450ms 稳定，后台同时重新请求 |
| 浏览器后退 | 184ms | 显示缓存的外框；340ms 时各区块先显示骨架，约 1.2s 内补齐 |
| 整页刷新 | 2.5-3.4s / 3.5-4.1s | 标题出现 / 数据行出现（共 3 次） |

预览实现：mock 数据统一加 600-800ms 延迟，并实现「首次加载转圈 → 骨架行 → 数据」和「再次进入直接显示缓存」两条路径；否则本地全是秒开，看不出这种风格。

### 列表操作

- **排序和翻页**：5ms 内把状态写进 URL（如 `?sort=name:asc&page=1`）→ 表格主体淡出到半透明（150ms），旧数据留在原地 → 新数据到了再淡入。全程不出骨架屏、不清空表格。排序只存在 URL 里，不会记住。
- **勾选**：约 20ms 内生效，没有动画；表格上方的配额行原地替换成批量操作栏：「已选择 N/总数 · 清除选择 · 选择全部 N 个符合条件的记录」，右侧是「编辑 N 个」和「删除 N 个」。（原站清除选择后表格会上移约 36px 跳一下，实现时应给批量栏固定高度，避免跳动。）
- **行内编辑**：约 20ms 内在当前行下方原地展开，没有动画；展开区左侧一条 3px 主色竖线，行尾按钮「编辑」变成「关闭」；字段已填好当前值，没改动之前「保存」禁用。

### 保存、删除与反馈

- **保存（不乐观）**：点击后 27ms 按钮禁用并出现加载图标；等服务器确认后才关弹窗、显示新行、配额 +1（实测约 3.1s）。
- **删除（乐观）**：确认后 55ms 内确认框关闭、这一行直接从表格里消失；服务器返回后再刷新配额（实测约 6.4s）。
- **删除确认框**：`role=alertdialog`，512px 宽；标题「删除记录」+ 一句「是否确实要删除此记录？」+ 一张小表格完整列出要删除的记录；**默认焦点在「取消」上**；不需要输入名称来二次确认。
- **Toast**：DNS 的新增和删除都**不弹 Toast**，结果直接体现在界面上（弹窗关闭、行增减、配额数字变化）。Toast 容器固定在右下角，距右边和底边各 32px，宽 340px，`aria-live="polite"`，留给异步或跨页面的通知；它在哪些场景出现、长什么样，没有实测到。
- **表单校验**：边输入边检查，输入第一个字符就报错；报错样式是输入框 1px 红色描边（#FB2C36）+ 下方 13px 深红文字（#C10007），不带图标，文字通过 `aria-describedby` 关联到输入框；改对后立刻消失；表单无效时「保存」一直禁用。
- **Esc**：即使表单里填了内容，按 Esc 也直接关闭弹窗，不问「放弃修改？」。

### 侧边栏收起与悬浮展开

- **收起**：宽度 260→57px，250ms `cubic-bezier(.77,0,.175,1)`，主内容随之变宽。动画过程中内层保持 260px 宽，只裁外壳，文字不挤不换行。
- **悬浮展开**：收起态鼠标移入约 75–105ms 后以 fixed 浮层展开到 260px（z-index 40），盖在内容上不推开，无阴影只有右边框；移出约 50ms 后收回。
- **收起按钮**：34×34、8px 圆角，悬停 #F3F3F3 底 + 图标加深；`aria-label` 在 Collapse/Expand sidebar 间切换。

### 动画参数（实测）

| 场景 | 动画 | 时长 | 缓动 |
|---|---|---|---|
| 弹窗、确认框、提示气泡的入场和退场 | 缩放 0.9→1 + 透明度 0→1，退场反向 | 150ms | `cubic-bezier(.4,0,.2,1)` |
| 侧边栏分组展开 | 高度（`grid-template-rows`） | 250ms | `cubic-bezier(.77,0,.175,1)` |
| 侧边栏收起/展开 | 宽度 | 250ms | `cubic-bezier(.77,0,.175,1)` |
| 收起按钮图标 | 内部竖线左右位移 | 250ms | 同上 |
| 同上，子菜单淡入 / 箭头旋转 | 透明度 / 旋转 | 150ms / 200ms | `cubic-bezier(.4,0,.2,1)` |
| 悬停（侧栏项、按钮） | 背景、描边**立刻变**；只有文字颜色可 150ms 过渡 | 0 / 150ms | — |
| 表格刷新数据 | 透明度（淡出到半透明再淡入） | 150ms | `cubic-bezier(.4,0,.2,1)` |
| 抽屉 | 位移 + 主内容右边距 | 300ms | `cubic-bezier(.4,0,.2,1)` |
| Ctrl K 搜索面板 | **没有入场动画**，约 108ms 直接出现 | — | — |
| 勾选、行内展开、批量操作栏 | **没有动画**，直接切换 | — | — |

- 悬停不做背景色过渡（官方规则 hover-color-transitions；原站搜索框 250ms、模板按钮 100ms 是例外，不照搬）。
- 按下按钮时不会缩小，也不会下沉。
- 所有动画都要支持系统的「减少动画」设置（原站用 `motion-reduce:transition-none`）。

### 聚焦与键盘

- **聚焦环分两种**：
  - 鼠标点击后：1.5px、50% 透明度的近黑色描边（不是蓝色）。
  - 键盘 Tab 聚焦时：2px 主色描边。
- **打开弹窗时**：焦点落在右上角的关闭按钮上；打开删除确认框时，焦点落在「取消」上。
- **提示气泡**：鼠标停留约 200ms 后出现。
- **Ctrl K 快速搜索**：
  - 面板贴在页面上方，不是垂直居中。
  - 内容分「最近访问」和「搜索提示」两组；搜索提示是作用域前缀，比如输入 `d1:` 就只在 D1 数据库里搜。
  - 第一项默认高亮，右侧带一个 → 箭头。
  - 输入时每个键都在约 20-90ms 内用本地数据刷新结果；停止输入约 300ms 后才发服务端请求，再把结果合并进来。
  - 匹配文字用 `<mark>` 高亮：警告橙 50% 透明度，4px 圆角。
  - 底部有键盘提示「↑↓ 导航、↵ 选择」，右上角有 Esc 标签。

## 图标

- **工具类图标**：用 **Phosphor Icons**（Regular 字重），尺寸只有 12、14、16px 三档，颜色用 `currentColor` 跟随文字。实测用到的有 MagnifyingGlass、CaretUpDown、Plus、ArrowBendUpLeft、ArrowSquareOut。
- **侧边栏产品图标**：一套自定义的 16×16 图标，线宽约 1px，统一 `opacity: .5`；悬停和选中时**透明度都不变**，只有背景变化。实现时用 Phosphor 的 Light 字重加 `opacity: .5` 来近似。
- **收起按钮图标**：18px 圆角矩形 + 一条竖线；展开时竖线在左，收起时滑到右（位移 9.5px），和侧栏宽度动画同步。
- **侧边栏右侧箭头**：12px，`opacity: .4`；展开分组时旋转 200ms。
- **图标和文字的位置**：按钮里图标放在文字前面，间距 6px；表头 ⓘ 放在列名后面；复制按钮放在哈希或 ID 后面。多行文字前的图标与第一行居中对齐（`h-lh flex items-center`）。
- **彩色图标**：只有品牌元素（Logo、"已代理"橙色云朵）是彩色的，其余图标都不单独设颜色。

  - **开箱一致**：侧栏 260/57px、头部 58px 自带底边（十字线自动对齐）、收起按钮图标、`peekable` 悬浮展开（fixed、z-index 40、无阴影）、主次按钮。
  - **必须自己补**：
    - 侧栏满高：`aside` 只有 `h-full`、父级只有 `min-h`，要加 `position: sticky; top: 0; height: 100svh`，并给 aside `z-index` 高于顶栏（sticky 会新建层叠上下文，否则浮出的面板被顶栏盖住）。
    - 收起态隐藏自定义内容：品牌文字、搜索框靠 `aside[data-state="collapsed"]` 自己隐藏或缩成图标。`Sidebar.Content` 自带横向内边距，自定义块不要再叠一层，否则图标对不齐。
    - 悬浮延迟：Kumo 鼠标移入 7–9ms 就展开，原站 73–105ms（移出约 50ms），要自己加延迟。
    - 侧栏搜索框（Kumo 没有这个组件）、顶栏和内容区布局、加载节奏（`SkeletonLine` 能用，转圈 → 骨架 → 数据和缓存要自己写）、Ctrl K 的内容（最近访问、作用域前缀）。
  - **和原站不同，要覆盖**：Table 行高 51px（原站 40px，原站表格不是 Kumo Table）；CommandPalette 带 150ms 缩放淡入（原站无入场动画）；侧栏项文字过渡 250ms（原站 150ms）。
  - 弹窗用 `open` 属性控制显示，不要条件渲染（否则没有开关动画）。
  - Vue 项目用不了 Kumo，继续只模仿 token。
- **Tailwind + Headless UI（Base UI、Radix）**：最接近原站。用 neutral 色阶，描边用 `ring-1 ring-black/10`，浮层用 `data-[starting-style]` / `data-[ending-style]` 做缩放淡入；图标用 `@phosphor-icons/react`（Vue 项目用 `@phosphor-icons/vue`）。
- **AntD**：
  - token 设 `borderRadius: 8`、`controlHeight: 36`、`colorPrimary: var(--op-primary)`。
  - 关掉默认阴影和描边色，改成上面的 ring 描边；主按钮另写渐变样式。
  - 用 Table 的 `expandable` 做行内编辑，`Modal` 的动画时长改成 150ms。
- **Element Plus**：覆盖 `--el-border-radius-base: 8px`、`--el-component-size: 36px`；主按钮另写渐变；用 `el-table` 的 `expand` 列做行内编辑。
- **无组件库**：用 CSS 变量加上面的阴影描边体系；排序、翻页状态写进 URL；mock 请求统一加延迟，用来演示分阶段加载。
