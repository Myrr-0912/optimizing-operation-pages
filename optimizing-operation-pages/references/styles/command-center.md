# 风格包：command-center（暗色驾驶舱）

**适用**：监控、调度、运维、风险处理——实时状态优先，长时间值守，暗色减少视觉疲劳。
**不适用**：数据录入为主的表单页、打印/导出频繁的页面。

## Design Token

| 维度 | 取值 |
|---|---|
| 信息密度 | 紧凑到中等：KPI 区宽松，明细区紧凑 |
| 字号 | 正文 13px；KPI 数字 24-32px 等宽字体 |
| 间距 | 基准 8px；KPI 卡间 16px |
| 圆角 | 6-8px |
| 边框 | 深色分层：背景 #0f1115 级，卡片 #171a21 级，边框低对比 |
| 色彩 | 高对比状态色是主角：正常青/绿、警告琥珀、危险红、信息蓝；文字 #e6e8ee 级 |
| 动效 | 强调状态反馈：数值变化、告警脉冲，但不干扰阅读 |

## 主题色候选（3 选 1，默认第一个）

主题色只换主操作/选中/链接的强调色，深色底与状态色体系（警告琥珀、危险红等）保持不变。

| id | 名称 | primary | hover | active | soft（暗底晕染） |
|---|---|---|---|---|---|
| `cyber-cyan` | 赛博青（默认） | #06B6D4 | #22D3EE | #0891B2 | rgba(6,182,212,.15) |
| `tech-blue` | 科技蓝 | #3B82F6 | #60A5FA | #2563EB | rgba(59,130,246,.15) |
| `emerald` | 翠绿 | #10B981 | #34D399 | #059669 | rgba(16,185,129,.15) |

翠绿主题下"正常"状态色改用青 #22D3EE，避免与主色混淆。

## 字体候选（2 选 1，默认第一个；每项同时决定正文与 KPI 数字字体；全部系统自带字体，零加载）

| id | 名称 | 正文 font-family | KPI 数字 font-family（--op-font-numeric） |
|---|---|---|---|
| `yahei-consolas` | 雅黑 + Consolas（默认） | -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif | Consolas, "Cascadia Mono", "SF Mono", monospace |
| `dengxian-cascadia` | 等线 + Cascadia | "DengXian", "等线", "PingFang SC", "Microsoft YaHei", sans-serif | "Cascadia Mono", Consolas, "SF Mono", monospace |

macOS 无雅黑/等线时回退苹方，Cascadia 缺失时回退 Consolas/SF Mono，不算缺陷。

## 布局骨架

分栏工作台：顶部 KPI 卡行（总量/待处理/异常/金额等 4-6 个实时指标，可点击过滤）→ 主体分栏（左侧数据表 + 右侧详情/趋势侧栏，或全宽表格 + 抽屉详情）。

## 组件规则

- **表格**：深色斑马纹、状态点/发光标签、高风险行左侧色条、等宽数字；异常行排序置顶可选。
- **筛选**：KPI 卡即筛选入口 + 顶部工具条补充条件。
- **表单/弹窗**：深色抽屉；输入控件深底浅字，焦点高亮描边。
- **操作层级**：主操作高对比实心；危险操作红色描边 + 确认；批量操作浮出式操作条。
- **状态**：加载用脉冲骨架；错误横幅置顶 + 重试；空状态说明"当前无异常"是好事还是筛选过窄。

## 对比度要求

暗色下必须复验对比度：正文 ≥ 4.5:1，状态色文字配浅底或加深文字，不允许纯色小字号低对比。

## 实现映射

AntD：`theme.darkAlgorithm` + token 覆盖。Element Plus：dark 模式 CSS 变量。无组件库：CSS 变量双层背景 + 状态色体系。
