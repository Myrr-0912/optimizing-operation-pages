# 风格包：enterprise-dense（企业高密度）

**适用**：订单、审核、财务、运营后台——用户整天盯着它处理大量条目，扫描效率压倒一切。
**不适用**：低频使用的配置页、面向新手的表单。

## Design Token

| 维度 | 取值 |
|---|---|
| 信息密度 | 紧凑：行高 32-36px 表格行，组件 size=small |
| 字号 | 正文 13px，辅助 12px，页面标题 16px |
| 间距 | 基准 8px，区块间 12px |
| 圆角 | 2-4px，近直角 |
| 边框 | 显式 1px 边框划分区域，弱阴影或无阴影 |
| 色彩 | 中性灰底 + 品牌色仅用于主操作和链接；状态色饱和度中等 |
| 动效 | 克制：仅 hover/展开，≤150ms |

## 主题色候选（3 选 1，默认第一个）

| id | 名称 | primary | hover | active | soft |
|---|---|---|---|---|---|
| `classic-blue` | 经典蓝（默认） | #1677FF | #4096FF | #0958D9 | #E6F4FF |
| `indigo` | 靛蓝 | #4F46E5 | #6366F1 | #4338CA | #EEF2FF |
| `teal-deep` | 青碧 | #0F766E | #0D9488 | #115E59 | #F0FDFA |

## 字体候选（2 选 1，默认第一个；全部系统自带字体，零加载，中文差异肉眼可见）

| id | 名称 | font-family |
|---|---|---|
| `yahei` | 雅黑（默认） | -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif |
| `dengxian` | 等线（更轻瘦） | "DengXian", "等线", "PingFang SC", "Microsoft YaHei", sans-serif |

金额与数字列统一 `font-variant-numeric: tabular-nums`。macOS 无雅黑/等线时回退苹方，不算缺陷。

## 布局骨架

单平面布局：页头（标题+全局操作）→ 筛选条（单行，高频筛选常驻+更多筛选折叠）→ 工具栏（批量操作+计数）→ 高密度表格 → 分页。无卡片包裹，靠边框和背景分区。

## 组件规则

- **表格**：斑马纹或分割线、固定表头、关键列固定、金额右对齐等宽数字、状态用小号彩色标签；行内操作 ≤3 个 + "更多"。
- **筛选**：单行工具条式，改动即生效或显式查询按钮，已选条件以可移除标签显示。
- **表单/弹窗**：抽屉优先（不打断列表上下文）；表单双列、label 左置。
- **操作层级**：主操作实心按钮仅一个；次操作描边/文字；危险操作收进"更多"且确认框说明后果。
- **状态**：加载用表格骨架行；空状态带"清空筛选"动作；错误给重试。

## 实现映射

AntD：`size="small"` + `ConfigProvider` token（borderRadius: 4, fontSize: 13）+ ProTable 风格布局。Element Plus：`size="small"` + 紧凑主题变量。无组件库：语义化 table + 4px 栅格 CSS。
