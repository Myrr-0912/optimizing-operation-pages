# 风格包：modern-clean（现代清爽）

**适用**：通用业务系统、客户管理、中低频操作页——可读性与亲和度优先，用户不必整天盯着。
**不适用**：单屏必须塞下大量条目的高频处理台。

## Design Token

| 维度 | 取值 |
|---|---|
| 信息密度 | 中等：表格行高 44-48px，组件默认 size |
| 字号 | 正文 14px，辅助 13px，页面标题 18-20px |
| 间距 | 基准 12px，区块间 16-24px，大留白 |
| 圆角 | 8-12px |
| 边框 | 弱边框或无边框，用卡片背景 + 轻阴影分区 |
| 色彩 | 白底 + 低饱和品牌色；状态用浅底深字药丸标签 |
| 动效 | 适中：过渡 200ms，hover 浮起 |

## 字体候选（2 选 1，默认第一个；全部系统自带字体，零加载，中文差异肉眼可见）

| id | 名称 | font-family |
|---|---|---|
| `yahei` | 雅黑（默认） | -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif |
| `dengxian` | 等线（更轻瘦） | "DengXian", "等线", "PingFang SC", "Microsoft YaHei", sans-serif |

macOS 无雅黑/等线时回退苹方，不算缺陷。

## 布局骨架

卡片分区布局:页头（标题 + 摘要统计卡）→ 状态页签 → 搜索卡（一个聚合搜索框 + 少量常用筛选，其余折叠）→ 数据卡片（表格或卡片列表）。区块之间靠留白与卡片边界分隔。

## 组件规则

- **表格**：无竖线、宽行距、主次信息两行合并列（订单号+交易号）、头像/图标增强识别；列数 ≤8。
- **筛选**：聚合搜索框优先（一个框查多个字段）+ 日期快捷区间；已选条件标签化。
- **表单/弹窗**：模态或整页表单，单列、分组标题、label 上置，就近校验提示。
- **操作层级**：主操作醒目圆角实心；行内只留 1-2 个高频 + "更多"；危险操作二次确认带后果说明。
- **状态**：骨架屏加载；插画式空状态；成功用轻提示 + 结果说明。

## 实现映射

AntD：默认尺寸 + ConfigProvider（borderRadius: 10）+ Card/Tabs/Segmented。Element Plus / Arco / Naive / TDesign：默认尺寸 + 圆角与阴影主题变量。无组件库：卡片栅格 + CSS 变量。
