# 未知框架 / 静态兜底

**触发条件**：framework=unknown、老旧技术栈（jQuery/服务端模板）、无法安装依赖或无网络。

## 做法

- 用 `--stack static` 初始化：无构建、无依赖，`variants/<id>/index.html` 每套一个纯 HTML/CSS/JS 页面，`manifest.js` 注册后直接浏览器打开壳 `index.html`。
- 风格包 token 落成 CSS 变量；交互用原生 JS 实现到能演示任务链的程度（筛选、选中、确认弹层、五种状态切换）。
- 模拟数据内联在 `mock/` 的 JS 文件里，`<script>` 引入。

## 限制（必须告知用户）

- 静态预览演示的是视觉与交互意图，不是可直接移植的组件代码。
- **自动落地范围受限**：老旧/未知栈的真实改造只能做保守的样式与结构调整，或输出改造计划由用户团队实施；落地方式必须由用户确认，不得猜测性重写。
